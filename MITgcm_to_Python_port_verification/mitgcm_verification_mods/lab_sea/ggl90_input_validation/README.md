# `lab_sea` + GGL90: CONSTRUCTED run-input files (1DMIX-054)

**These files are constructed by this project. They are NOT a stock MITgcm experiment**: no
`data.ggl90` exists for `lab_sea` anywhere in the MITgcm tree (its `code/packages.conf` has no `ggl90`
line and its `input*/data.pkg` never set `useGGL90`). The MITgcm reference values still come only
from a real MITgcm run (recipes G6/G7 in `GGL90_port_validation/CAPTURES.md`).

Companion: `../ggl90_code_validation/` (compile side: the stock `code/` headers, with the same single-tile
`SIZE.h` edit as `../code_validation/` (20x16, `nSx=nSy=1`) so the tile layout matches the existing KPP
captures; `ggl90` added to `packages.conf`; `ggl90_calc.F` symlinked to `../../ggl90_mods/`; MITgcm's
default `GGL90_OPTIONS.h`). The run restarts from the stock `pickup.0000000001` at `startTime=3600 s`,
`deltaT=3600 s`, exactly as the existing KPP captures do (`KPP_port_validation/CAPTURES.md` recipes R3/R5), with the
two durations of those recipes (`endTime=3600000.` -> 999 steps, `endTime=15728400.` -> 4368 steps).

## Why `data.ggl90` has no non-default parameter

GGL90 has no stock namelist for this grid, and this project's other GGL90 namelists are tuned for other
geometries: `vermix` (`GGL90TKEmin=1E-7`, `mxlMaxFlag=3`, `GGL90mixingLengthMin=3`, `GGL90writeState`: a 1-D
26-level column; also the inferred `1D_ocean_ice_column` recipe G5), the `global_ocean` IDEMIX namelists
(`GGL90alpha=30`, `GGL90m2=3`, `GGL90TKEmin=0`, `GGL90TKEbottom=4E-6`, `mxlMaxFlag=2`, `useIDEMIX`, `calcMeanVertShear`:
global 15-level configurations with an IDEMIX energy budget) and `global_oce_latlon/input_ad.ggl90`
(`GGL90alpha=30`, Langmuir). Nothing in `lab_sea`'s own geometry (23 levels, 10-500 m) or forcing (1979 forcing,
sea ice, `deltaT=3600 s`) determines any of them, so none was copied; the MITgcm defaults are the only choice
that adds no unjustified assumption. The stock background mixing `viscAz=1.93e-5`, `diffKzT=diffKzS=1.46e-5`
stays in `data` and acts as the GGL90 floor.

## Why a constructed `pickup_ggl90.0000000001`

`nIter0=1` (from `startTime`/`deltaT`) makes `GGL90_INIT_VARIA` call `GGL90_READ_PICKUP`, which STOPs if
`pickup_ggl90.0000000001` is missing; KPP is diagnostic and the stock input never had one. The file holds the
TKE field a cold start would have: `GGL90_INIT_VARIA` sets `GGL90TKE = GGL90TKEmin * maskC` (non-IDEMIX branch) and
`GGL90TKEmin` is the default `1.E-11` (dry points are filled with the same value; they are never used). The ocean,
sea-ice and CD-scheme state come from the stock pickups. This is an initial condition, not a reference value.

## Reproduce

```bash
export MITGCM_ROOT=~/Projects/MITgcm
./assemble_run_dir.sh 999        # or 6mo: creates verification/lab_sea/input.ggl90_999 (layered on input/ by the run script)
cd $MITGCM_ROOT/verification
./experiment_compile.sh lab_sea -mods <repo>/MITgcm_to_Python_port_verification/mitgcm_verification_mods/lab_sea/ggl90_code_validation -build build_docker_ggl90_054 -clean -j 8
./experiment_run_no_compile.sh lab_sea input.ggl90_999 -build build_docker_ggl90_054 -output output_ggl90_999_054
cd <repo> && python3 MITgcm_to_Python_port_verification/scripts/parse_mitgcm_ggl90_split.py $MITGCM_ROOT/verification/lab_sea/output_ggl90_999_054/output.txt lab_sea
```

The first 999 steps of the 6-month run are bitwise identical to the 999-step run (measured).
