--------------------------------------------------------------------------------
WHY 27% DIFFERENCE?
--------------------------------------------------------------------------------

All inputs match, all parameters match, grid matches.
Must be in physics calculation:

  Ri = (N² × depth²) / (S² + ε)

where:
  N² = stratification = -(g/ρ₀) × (∂ρ/∂z)
  S² = shear = (∂u/∂z)² + (∂v/∂z)²

hbl = depth where Ri first exceeds Ricr = 0.3

Likely causes:
  - Different derivative calculations (finite differences)
  - Grid staggering interpretation differences  
  - Averaging scheme differences
