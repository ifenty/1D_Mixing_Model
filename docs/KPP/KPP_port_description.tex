\section{Introduction}
\label{sec:introduction}

\subsection{Purpose of This Document}

This document serves as a \textbf{reference guide} for mapping the MITgcm KPP (K-Profile Parameterization) mixing scheme (Fortran) to its Python port in the 1D Column Model. The document is organized by algorithm flow, providing file and line number references for each major computational step. Use this document to:

\begin{itemize}
    \item Trace where specific KPP capabilities from MITgcm are implemented in Python
    \item Understand the computational flow of the KPP mixing scheme
    \item Locate corresponding code sections when comparing Fortran and Python implementations
    \item Identify file-to-file correspondence between the two implementations
\end{itemize}

\subsection{Scope of the Port}

The Python port implements the KPP boundary layer parameterization for a 1D ocean column. The port faithfully reproduces the core physics and numerical methods from MITgcm's \verb|pkg/kpp|, adapted for the 1D vertical column context.

\textbf{Included in the port:}
\begin{itemize}
    \item Boundary layer depth diagnosis (bulk Richardson criterion)
    \item Surface forcing calculation (friction velocity, buoyancy forcing)
    \item Interior Richardson number-based mixing
    \item Boundary layer mixing profiles (cubic shape functions)
    \item Nonlocal transport (counter-gradient term)
    \item Diffusivity assembly (interior + boundary layer)
    \item Enhancement at boundary layer interface
    \item Stratification and shear diagnostics
    \item Shortwave penetration (single Jerlov water type)
\end{itemize}

\textbf{Excluded from the 1D port:}
\begin{itemize}
    \item Horizontal mixing and advection
    \item Horizontal smoothing of buoyancy gradients (requires 2D/3D data)
    \item Double diffusion parameterization (not critical for 1D validation)
    \item Salt plume parameterization
    \item Multiple Jerlov water types (simplified to single type)
    \item 3D-specific features (requires horizontal neighbors)
\end{itemize}

\section{Overview of Code Flow}
\label{sec:overview}

\subsection{Algorithm Flowchart}

The KPP scheme computes vertical mixing coefficients through the following sequence:

\begin{enumerate}
    \item \textbf{Parameter Initialization}: Load scheme parameters from configuration files
    \item \textbf{Density and Buoyancy Calculation}: Compute density, buoyancy gradients, and thermal expansion coefficients
    \item \textbf{Boundary Layer Depth Diagnosis}: Find boundary layer depth using bulk Richardson criterion
    \item \textbf{Surface Forcing Calculation}: Compute surface friction velocity and buoyancy forcing
    \item \textbf{Interior Richardson Mixing}: Compute diffusivity below boundary layer based on local Ri
    \item \textbf{Boundary Layer Mixing}: Compute mixing within boundary layer using shape functions
    \item \textbf{Nonlocal Transport}: Calculate counter-gradient flux term
    \item \textbf{Diffusivity Assembly}: Combine interior and boundary layer contributions
    \item \textbf{Enhancement at Interface}: Enhance mixing at boundary layer base
\end{enumerate}

\subsection{Density and Buoyancy Calculation}

\textbf{Purpose}: Compute density, buoyancy gradients (dbloc), surface buoyancy relative to depth (Ritop), and thermal expansion/haline contraction coefficients. These are fundamental inputs for Richardson number and boundary layer depth diagnosis.

\textbf{Python Implementation}:
\begin{itemize}
    \item File: \verb|main/eos.py|
    \item Function: \verb|compute_buoyancy_gradients()| (lines 1-200+)
    \item Called from: \verb|kpp_core_driver.py::compute_mixing()| (lines 184-186)
    \item Returns: \verb|rho_surf|, \verb|dbloc|, \verb|dbsfc|, \verb|ttalpha|, \verb|ssbeta|
    \item Uses JMD95 equation of state (simplified for 1D)
\end{itemize}

\textbf{Fortran Source}:
\begin{itemize}
    \item File: \verb|pkg/kpp/kpp_routines.F|
    \item Subroutine: \verb|STATEKPP| (lines 1766-1961)
    \item Called from: \verb|kpp_calc.F::KPP_CALC| (line 300+)
    \item Computes: \verb|rho1|, \verb|dbloc|, \verb|dbsfc|, \verb|ttalpha|, \verb|ssbeta|
    \item Uses model equation of state (\verb|find_rho.F|)
\end{itemize}

\textbf{Key Computations}:

Local buoyancy gradient across interface k:
\begin{equation}
\text{dbloc}[k] = g \frac{\rho[k] - \rho[k-1]}{\rho_0}
\end{equation}

Surface buoyancy difference (numerator of bulk Ri):
\begin{equation}
\text{Ritop}[k] = (z_{\text{ref}} - z[k]) \times g \frac{\rho[k] - \rho_{\text{surf}}}{\rho_0}
\end{equation}

\textbf{Implementation Notes}:
\begin{itemize}
    \item Python uses JMD95 simplified equation of state
    \item Fortran calls full MITgcm EOS (can be linear, JMD95, MDJWF, etc.)
    \item Both compute potential density (not in-situ) for consistency
\end{itemize}

\subsection{Boundary Layer Depth Diagnosis}

\textbf{Purpose}: Diagnose the ocean boundary layer depth (hbl) by finding the depth where the bulk Richardson number exceeds a critical threshold. This determines the extent of surface-driven turbulent mixing.

\textbf{Python Implementation}:
\begin{itemize}
    \item File: \verb|KPP_ML/KPP_PY/kpp_scheme_specific.py|
    \item Function: \verb|diagnose_bl_depth()| (lines 26-200+)
    \item Called from: \verb|kpp_core_driver.py::compute_mixing()| (line 210+)
    \item Key computation: lines 94-144 (Rib loop and comparison to Ricr)
    \item Interpolation: lines 146-180+ (linear interpolation to find exact hbl)
    \item Returns: \verb|hbl|, \verb|bfsfc|, \verb|stable|, \verb|casea|, \verb|kbl|, \verb|Rib|
\end{itemize}

\textbf{Fortran Source}:
\begin{itemize}
    \item File: \verb|pkg/kpp/kpp_routines.F|
    \item Function: \verb|BLDEPTH| (internal to KPPMIX, lines 600-800+)
    \item Called from: \verb|KPPMIX| (line 400+)
    \item Richardson number loop: lines 630-700+
    \item Interpolation: lines 660-680+
    \item Returns: \verb|hbl(i)|, \verb|kbl(i)|
\end{itemize}

\textbf{Key Computation}:

Bulk Richardson number at depth z:
\begin{equation}
\text{Ri}_b(z) = \frac{\text{Ritop}(z)}{\text{dvsq}(z) + V_t^2 + \phi_\epsilon}
\end{equation}

where:
\begin{itemize}
    \item $\text{Ritop}(z)$ = $(z_{\text{ref}} - z) \times$ buoyancy difference from surface
    \item $\text{dvsq}(z)$ = velocity shear squared relative to surface
    \item $V_t^2$ = unresolved turbulent shear contribution
    \item $\phi_\epsilon$ = small regularization parameter
\end{itemize}

Boundary layer depth is where $\text{Ri}_b = \text{Ri}_c$ (typically 0.3):
\begin{equation}
\text{hbl} = z \quad \text{where} \quad \text{Ri}_b(z) = \text{Ri}_c
\end{equation}

\textbf{Implementation Notes}:
\begin{itemize}
    \item Linear interpolation between grid levels to find exact hbl
    \item Shortwave penetration reduces effective surface buoyancy forcing at depth
    \item Interpolation includes guard to prevent accessing array bounds beyond bottom level
    \item Stable vs. unstable forcing determines velocity scale computation
\end{itemize}

\subsection{Surface Forcing Calculation}

\textbf{Purpose}: Compute surface friction velocity (u$_*$) and surface buoyancy forcing (bo, bosol) from atmospheric fluxes. These drive the boundary layer turbulence.

\textbf{Python Implementation}:
\begin{itemize}
    \item File: \verb|KPP_ML/KPP_PY/kpp_core_driver.py|
    \item Method: \verb|KPPDriver._compute_surface_forcing()| (lines 250-320+)
    \item Called from: \verb|compute_mixing()| (lines 193-196)
    \item Friction velocity: $u_*^2 = \sqrt{\tau_x^2 + \tau_y^2}$ (line 260+)
    \item Buoyancy forcing: \verb|bo| (turbulent) and \verb|bosol| (radiative) (lines 280-310+)
\end{itemize}

\textbf{Fortran Source}:
\begin{itemize}
    \item File: \verb|pkg/kpp/kpp_forcing_surf.F|
    \item Subroutine: \verb|KPP_FORCING_SURF| (lines 1-500+)
    \item Called from: \verb|kpp_calc.F::KPP_CALC| (line 150+)
    \item Friction velocity: lines 200-250+ (from wind stress)
    \item Buoyancy forcing: lines 300-400+ (from heat/freshwater fluxes)
\end{itemize}

\textbf{Key Computations}:

Friction velocity:
\begin{equation}
u_* = \sqrt[4]{\tau_x^2 + \tau_y^2}
\end{equation}

Turbulent buoyancy forcing:
\begin{equation}
\text{bo} = g \left( \alpha \frac{Q_{\text{net}} - Q_{\text{sw}}}{\rho_0 c_p} - \beta S_{\text{surf}} (E - P - R) \right)
\end{equation}

Radiative buoyancy forcing:
\begin{equation}
\text{bosol} = g \alpha \frac{Q_{\text{sw}}}{\rho_0 c_p}
\end{equation}

where:
\begin{itemize}
    \item $\alpha$ = thermal expansion coefficient [1/K]
    \item $\beta$ = haline contraction coefficient [1/psu]
    \item $Q_{\text{net}}$ = net surface heat flux [W/m²]
    \item $Q_{\text{sw}}$ = shortwave radiation [W/m²]
    \item $E - P - R$ = freshwater flux [m/s]
\end{itemize}

\textbf{Implementation Notes}:
\begin{itemize}
    \item Positive heat flux = into ocean (warming)
    \item Positive freshwater flux = into ocean (freshening)
    \item \verb|bo| drives turbulent mixing (non-penetrating)
    \item \verb|bosol| penetrates with shortwave radiation
\end{itemize}

\subsection{Interior Richardson Mixing}

\textbf{Purpose}: Compute mixing coefficients in the ocean interior (below boundary layer) based on local Richardson number. This parameterizes shear instability and internal wave breaking.

\textbf{Python Implementation}:
\begin{itemize}
    \item File: \verb|KPP_ML/KPP_PY/kpp_routines.py|
    \item Function: \verb|ri_iwmix()| (lines 100-250+)
    \item Called from: \verb|kpp_core_driver.py::compute_mixing()| (line 205+)
    \item Richardson number: $\text{Ri} = N^2 / S^2$ (line 120+)
    \item Diffusivity: $\kappa = \nu_0 / (1 + a \text{Ri})^n$ (lines 140-180+)
\end{itemize}

\textbf{Fortran Source}:
\begin{itemize}
    \item File: \verb|pkg/kpp/kpp_routines.F|
    \item Function: \verb|RI_IWMIX| (internal to KPPMIX, lines 1450-1600+)
    \item Called from: \verb|KPPMIX| (line 500+)
    \item Richardson number: lines 1480-1510+
    \item Diffusivity formula: lines 1520-1560+
\end{itemize}

\textbf{Key Computation}:

Local Richardson number:
\begin{equation}
\text{Ri} = \frac{N^2}{S^2 + \epsilon}
\end{equation}

Interior diffusivity (Pacanowski \& Philander 1981 functional form):
\begin{equation}
\kappa = \frac{\nu_0}{(1 + a \text{Ri})^n} + \kappa_{\text{background}}
\end{equation}

Typical values:
\begin{itemize}
    \item $\nu_0$ = 5.0e-3 m²/s (maximum diffusivity)
    \item $a$ = 5.0 (empirical coefficient)
    \item $n$ = 2.0 (empirical exponent)
    \item $\kappa_{\text{background}}$ = 1.0e-5 m²/s (background diffusivity)
\end{itemize}

\textbf{Implementation Notes}:
\begin{itemize}
    \item Applied only below boundary layer (z $<$ -hbl)
    \item Small $\epsilon$ regularizes division by zero when S² = 0
    \item Large Ri (stable) $\rightarrow$ small diffusivity
    \item Small Ri (shear instability) $\rightarrow$ large diffusivity
\end{itemize}

\subsection{Boundary Layer Mixing (Shape Functions)}

\textbf{Purpose}: Compute vertical profiles of mixing coefficients within the boundary layer using non-dimensional shape functions. This represents the structure of surface-driven turbulence.

\textbf{Python Implementation}:
\begin{itemize}
    \item File: \verb|KPP_ML/KPP_PY/kpp_scheme_specific.py|
    \item Function: \verb|compute_bl_mixing()| (lines 200-400+)
    \item Called from: \verb|kpp_core_driver.py::compute_mixing()| (line 220+)
    \item Velocity scales: \verb|wscale()| computes w$_m$, w$_s$ (lines 250-280+)
    \item Shape functions: cubic polynomial $G(\sigma)$ (lines 300-350+)
    \item Diffusivity: $\kappa(\sigma) = h \times w_s \times G(\sigma)$ (lines 360-390+)
\end{itemize}

\textbf{Fortran Source}:
\begin{itemize}
    \item File: \verb|pkg/kpp/kpp_routines.F|
    \item Function: \verb|BLMIX| (internal to KPPMIX, lines 1050-1350+)
    \item Called from: \verb|KPPMIX| (line 550+)
    \item Function: \verb|WSCALE| (lines 900-1000+) computes velocity scales
    \item Shape function: lines 1150-1250+ (cubic profile)
    \item Diffusivity assembly: lines 1280-1330+
\end{itemize}

\textbf{Key Computations}:

Non-dimensional depth within boundary layer:
\begin{equation}
\sigma = -z / h_{\text{bl}} \quad (0 \leq \sigma \leq 1)
\end{equation}

Cubic shape function (Large et al. 1994):
\begin{equation}
G(\sigma) = \sigma (1 - \sigma)^2
\end{equation}

Velocity scales (Monin-Obukhov similarity, from lookup tables):
\begin{itemize}
    \item $w_m(\sigma, \zeta)$ = turbulent velocity scale for momentum
    \item $w_s(\sigma, \zeta)$ = turbulent velocity scale for scalars
    \item $\zeta = -h_{\text{bl}} / L$ = stability parameter (L = Obukhov length)
\end{itemize}

Boundary layer diffusivity:
\begin{equation}
\kappa_{\text{BL}}(z) = h_{\text{bl}} \times w_s(\sigma, \zeta) \times G(\sigma)
\end{equation}

\textbf{Implementation Notes}:
\begin{itemize}
    \item Shape function peaks at $\sigma \approx 0.33$ (one-third depth)
    \item Goes to zero at surface ($\sigma = 0$) and base ($\sigma = 1$)
    \item Velocity scales vary with stability (stable vs. unstable forcing)
    \item Lookup tables (wmt, wst) precomputed for efficiency
\end{itemize}

\subsection{Nonlocal Transport}

\textbf{Purpose}: Compute the counter-gradient flux term (ghat) for scalars in the unstably-forced boundary layer. This represents large-eddy transport not captured by downgradient diffusion.

\textbf{Python Implementation}:
\begin{itemize}
    \item File: \verb|KPP_ML/KPP_PY/kpp_scheme_specific.py|
    \item Computed within: \verb|compute_bl_mixing()| (lines 380-400+)
    \item Called from: \verb|kpp_core_driver.py::compute_mixing()| (line 220+)
    \item Formula: $\gamma(\sigma) = c_s \times \sigma \times (1 - \sigma)^2$ (line 390+)
    \item Applied when: unstable forcing (bo $>$ 0)
\end{itemize}

\textbf{Fortran Source}:
\begin{itemize}
    \item File: \verb|pkg/kpp/kpp_routines.F|
    \item Function: \verb|BLMIX| (lines 1050-1350+)
    \item Nonlocal term: lines 1200-1230+ (ghat computation)
    \item Shape function: $\gamma(\sigma)$ same cubic form
\end{itemize}

\textbf{Key Computation}:

Nonlocal transport shape function:
\begin{equation}
\gamma(\sigma) = c_s \times \sigma (1 - \sigma)^2
\end{equation}

Nonlocal flux:
\begin{equation}
\text{ghat}(z) = \gamma(\sigma) \times \frac{\text{bo}}{w_s \times h_{\text{bl}}}
\end{equation}

where:
\begin{itemize}
    \item $c_s$ = shape function coefficient (typically 10)
    \item \verb|bo| = surface buoyancy forcing [m²/s³]
    \item $w_s$ = turbulent velocity scale for scalars [m/s]
    \item Applied only for unstable forcing (bo $>$ 0)
\end{itemize}

\textbf{Implementation Notes}:
\begin{itemize}
    \item Nonlocal transport carries heat/salt vertically in convective boundary layers
    \item Represents counter-gradient flux (e.g., warm water transported downward in cooling conditions)
    \item Set to zero for stable forcing (bo $<$ 0)
    \item Peak at $\sigma \approx 0.33$ (same as shape function)
\end{itemize}

\subsection{Diffusivity Assembly}

\textbf{Purpose}: Combine interior and boundary layer mixing coefficients into final vertical profiles, ensuring smooth transitions and applying physical constraints.

\textbf{Python Implementation}:
\begin{itemize}
    \item File: \verb|KPP_ML/KPP_PY/kpp_core_driver.py|
    \item Assembly logic: \verb|compute_mixing()| (lines 230-270+)
    \item Bottom-to-top indexing: lines 240-250+ (interior below hbl, BL above)
    \item Re-indexing to top-of-cell: lines 260-270+ (MITgcm output convention)
    \item Background floor: applied at lines 265-268+
\end{itemize}

\textbf{Fortran Source}:
\begin{itemize}
    \item File: \verb|pkg/kpp/kpp_routines.F|
    \item Subroutine: \verb|KPPMIX| (lines 28-1765)
    \item Assembly: lines 700-900+ (combine interior + BL)
    \item File: \verb|pkg/kpp/kpp_calc.F|
    \item Export to model arrays: lines 550-650+ (\verb|KPPviscAz|, \verb|KPPdiffKzS|, \verb|KPPdiffKzT|)
\end{itemize}

\textbf{Key Operations}:

For each vertical level:
\begin{equation}
\kappa_{\text{total}}(z) = \begin{cases}
\kappa_{\text{BL}}(z) & \text{if } z > -h_{\text{bl}} \\
\kappa_{\text{interior}}(z) & \text{if } z \leq -h_{\text{bl}}
\end{cases}
\end{equation}

Background floor:
\begin{equation}
\kappa_{\text{final}}(z) = \max(\kappa_{\text{total}}(z), \kappa_{\text{background}})
\end{equation}

\textbf{Implementation Notes}:
\begin{itemize}
    \item Boundary layer coefficients override interior coefficients above -hbl
    \item Background diffusivity (MITgcm's \verb|diffKrNrS|, \verb|diffKrNrT|) applied as floor
    \item Enhancement at interface (next step) adds discontinuity at -hbl
    \item Python uses bottom-to-top assembly then re-indexes for MITgcm compatibility
\end{itemize}

\subsection{Enhancement at Interface}

\textbf{Purpose}: Apply an additional enhancement to mixing coefficients at the boundary layer base to represent entrainment processes and ensure smooth transition to interior mixing.

\textbf{Python Implementation}:
\begin{itemize}
    \item File: \verb|KPP_ML/KPP_PY/kpp_scheme_specific.py|
    \item Function: \verb|enhance_at_interface()| (lines 400-500+)
    \item Called from: \verb|kpp_core_driver.py::compute_mixing()| (line 240+)
    \item Enhancement factor: $f_{\text{enh}} = 1 + $ enhancement (lines 420-450+)
    \item Applied at: interface closest to -hbl (lines 460-480+)
\end{itemize}

\textbf{Fortran Source}:
\begin{itemize}
    \item File: \verb|pkg/kpp/kpp_routines.F|
    \item Function: \verb|ENHANCE| (internal to KPPMIX, lines 1350-1450+)
    \item Called from: \verb|KPPMIX| (line 600+)
    \item Enhancement logic: lines 1380-1420+
\end{itemize}

\textbf{Key Computation}:

Enhancement factor at boundary layer base:
\begin{equation}
f_{\text{enh}} = 1 + c_{\text{enh}} \times \delta
\end{equation}

where:
\begin{itemize}
    \item $c_{\text{enh}}$ = enhancement coefficient (parameter)
    \item $\delta$ = nondimensional function of shear and stratification at interface
\end{itemize}

Enhanced diffusivity:
\begin{equation}
\kappa_{\text{enhanced}} = f_{\text{enh}} \times \kappa_{\text{BL}}(z = -h_{\text{bl}})
\end{equation}

\textbf{Implementation Notes}:
\begin{itemize}
    \item Represents entrainment at boundary layer base
    \item Creates discontinuity in mixing profile at -hbl
    \item Applied only at the interface level (kbl in Fortran)
    \item Can be disabled by setting enhancement coefficient to zero
\end{itemize}

\section{Supporting Infrastructure}
\label{sec:infrastructure}

\subsection{Parameter Handling}

\textbf{Python Approach}:
\begin{itemize}
    \item YAML-based configuration file in \verb|configuration_yamls/|
    \item \verb|kpp_default.yaml|: MITgcm default parameters
    \item Parameters loaded into \verb|KPPParameters| dataclass
    \item All parameters have documented units and default values
\end{itemize}

\textbf{Fortran Approach}:
\begin{itemize}
    \item Namelist-based configuration (\verb|data.kpp| file)
    \item Namelist group: \verb|KPP_PARM01|
    \item Parameters read in \verb|kpp_readparms.F|
    \item Defaults defined in \verb|KPP_PARAMS.h| header file
    \item Parameters stored in COMMON blocks
\end{itemize}

\subsection{Grid and Coordinate System}

\textbf{Coordinate Conventions (both implementations)}:
\begin{itemize}
    \item \textbf{z-axis}: Positive upward, z = 0 at surface
    \item \textbf{depth}: Positive downward (depth = $-z$)
    \item \textbf{Vertical index k}: k=0 is shallowest (surface), k=nz-1 is deepest (bottom)
    \item \textbf{Vertical spacing}: \verb|dz[k]| or \verb|cell_thickness[k]| is thickness of cell k
\end{itemize}

\textbf{Staggering Conventions}:
\begin{itemize}
    \item Tracers (T, S) at cell centers
    \item Velocities (u, v) at cell centers (1D column)
    \item Mixing coefficients ($\kappa_m$, $\kappa_h$) at cell interfaces (top face)
    \item Nonlocal term (ghat) at cell interfaces (bottom face)
    \item Buoyancy gradients (dbloc) at cell interfaces
\end{itemize}

\textbf{Python vertical arrays}:
\begin{itemize}
    \item \verb|depth[k]|: depth of cell center k [m], positive
    \item \verb|cell_thickness[k]|: thickness of cell k [m]
    \item \verb|visc_az[k]|, \verb|diff_kz_s[k]|, \verb|diff_kz_t[k]|: mixing coefficients at top face of cell k [m²/s]
    \item \verb|ghat[k]|: nonlocal transport at bottom face of cell k [s/m²]
    \item Index 0 = surface face (set to 0)
\end{itemize}

\textbf{Fortran vertical arrays}:
\begin{itemize}
    \item \verb|rC(k)|: z-coordinate of cell center k [m]
    \item \verb|rF(k)|: z-coordinate of cell interface k [m]
    \item \verb|drF(k)|: thickness of cell k [m]
    \item \verb|KPPviscAz(i,j,k)|, \verb|KPPdiffKzS(i,j,k)|, \verb|KPPdiffKzT(i,j,k)|: mixing coefficients at top face [m²/s]
    \item \verb|KPPghat(i,j,k)|: nonlocal transport at bottom face [s/m²]
\end{itemize}

\subsection{Physical Constants}

\textbf{Common constants (both implementations)}:
\begin{itemize}
    \item \verb|gravity| (Python) = \verb|gravity| (Fortran) = 9.81 m/s²
    \item \verb|rho_const| (Python) = \verb|rhoConst| (Fortran) = 1029.0 kg/m³
    \item \verb|cp| = specific heat capacity = 3994.0 J/(kg K)
\end{itemize}

\textbf{KPP-specific constants}:
\begin{itemize}
    \item \verb|vonkarman| = von Kármán constant = 0.4
    \item \verb|zref| = reference depth for bulk Ri = 10.0 m (typically surface layer)
\end{itemize}

\subsection{Boundary Condition Details}

\textbf{Surface Boundary Conditions}:
\begin{itemize}
    \item Mixing coefficients: zero at surface (no surface diffusive flux)
    \item Surface forcing drives boundary layer depth and velocity scales
    \item Implemented by setting index 0 to zero
\end{itemize}

\textbf{Bottom Boundary Conditions}:
\begin{itemize}
    \item Interior mixing continues to bottom
    \item No special boundary layer treatment at bottom (KPP is surface-forced)
    \item Bottom stress could be included (not implemented in 1D port)
\end{itemize}

\textbf{No lateral boundaries in 1D column model}

\subsection{Unit Conversions}

All variables use consistent units between Python and Fortran:
\begin{itemize}
    \item Length: meters [m]
    \item Time: seconds [s]
    \item Temperature: degrees Celsius [°C]
    \item Salinity: practical salinity units [psu]
    \item Velocity: meters per second [m/s]
    \item Mixing coefficients: square meters per second [m²/s]
\end{itemize}

\subsection{Sign Convention Differences}

\textbf{No sign convention differences} between Python and Fortran implementations. Both use:
\begin{itemize}
    \item z-axis positive upward (z = 0 at surface, z < 0 below surface)
    \item depth positive downward (depth = $-z$)
    \item hbl positive (represents positive depth below surface)
    \item Positive buoyancy forcing = destabilizing (heating or freshening)
    \item Negative buoyancy forcing = stabilizing (cooling or salting)
\end{itemize}
