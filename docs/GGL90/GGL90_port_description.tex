\section{Introduction}
\label{sec:introduction}

\subsection{Purpose of This Document}

This document serves as a \textbf{reference guide} for mapping the MITgcm GGL90 turbulence closure scheme (Fortran) to its Python port in the 1D Column Model. The document is organized by algorithm flow, providing file and line number references for each major computational step. Use this document to:

\begin{itemize}
    \item Trace where specific GGL90 capabilities from MITgcm are implemented in Python
    \item Understand the computational flow of the GGL90 mixing scheme
    \item Locate corresponding code sections when comparing Fortran and Python implementations
    \item Identify file-to-file correspondence between the two implementations
\end{itemize}

\subsection{Scope of the Port}

The Python port implements the GGL90 turbulence closure scheme for a 1D ocean column. The port faithfully reproduces the core physics and numerical methods from MITgcm's \verb|pkg/ggl90|, adapted for the 1D vertical column context.

\textbf{Included in the port:}
\begin{itemize}
    \item TKE prognostic evolution with implicit time stepping
    \item Mixing length computation (multiple limiting methods)
    \item Eddy viscosity and diffusivity calculation
    \item TKE budget terms (production, buoyancy, dissipation)
    \item Surface and bottom boundary conditions for TKE
    \item Static instability handling (convective adjustment)
    \item Stratification (N²) and shear (S²) diagnostics
\end{itemize}

\textbf{Excluded from the 1D port:}
\begin{itemize}
    \item Horizontal mixing and advection
    \item IDEMIX internal wave energy model
    \item Langmuir circulation parameterization
    \item Grid-scale noise smoothing
    \item 3D-specific features (requires horizontal neighbors)
\end{itemize}

\section{Overview of Code Flow}
\label{sec:overview}

\subsection{Algorithm Flowchart}

The GGL90 scheme computes vertical mixing coefficients through the following sequence:

\begin{enumerate}
    \item \textbf{Parameter Initialization}: Load scheme parameters from configuration files
    \item \textbf{Stratification and Shear Calculation}: Compute N² (buoyancy frequency squared) and S² (vertical shear squared)
    \item \textbf{Mixing Length Calculation}: Compute turbulent mixing length $\ell$ with physical limits
    \item \textbf{TKE Evolution}: Step turbulent kinetic energy forward in time (prognostic)
    \item \textbf{Eddy Diffusivity Calculation}: Compute $\kappa_m$ (viscosity) and $\kappa_h$ (diffusivity)
    \item \textbf{Boundary Conditions}: Apply surface and bottom boundary conditions
    \item \textbf{Static Instability Handling}: Apply convective adjustment when needed
\end{enumerate}

\subsection{Mixing Length Calculation}

\textbf{Purpose}: Compute the turbulent mixing length scale $\ell$ based on TKE, stratification, and distance from boundaries. The mixing length determines the spatial scale of turbulent eddies.

\textbf{Python Implementation}:
\begin{itemize}
    \item File: \verb|GGL90_ML/GGL90_PY/ggl90_scheme_specific.py|
    \item Class: \verb|GGL90MixingLength| (lines 21-231)
    \item Method: \verb|compute()| (lines 37-101)
    \item Called from: \verb|ggl90_core_driver.py::compute_mixing()| (lines 323-325)
    \item Limiting methods:
        \begin{itemize}
            \item Method 0: \verb|_limit_method_0()| (lines 103-123) — water column depth limit
            \item Method 1: \verb|_limit_method_1()| (lines 125-145) — minimum distance to surface/bottom
            \item Method 2: \verb|_limit_method_2()| (lines 147-194) — two-way sweep (Blanke \& Delecluse 1993)
        \end{itemize}
\end{itemize}

\textbf{Fortran Source}:
\begin{itemize}
    \item File: \verb|pkg/ggl90/ggl90_mixinglength.F|
    \item Subroutine: \verb|GGL90_MIXINGLENGTH| (lines 10-380+)
    \item Called from: \verb|ggl90_calc.F::GGL90_CALC| (line 520+)
    \item Initial length computation: lines 100-150+ (equation 2.35 from Gaspar et al. 1990)
    \item Limiting logic: controlled by \verb|mxlMaxFlag| parameter
        \begin{itemize}
            \item Method 0: lines 200-250+ (simple depth limit)
            \item Method 1: lines 250-300+ (distance to boundaries)
            \item Method 2: lines 300-380+ (two-way sweep algorithm)
        \end{itemize}
\end{itemize}

\textbf{Key Computation}:

Initial mixing length from TKE and stratification (Gaspar et al. 1990, Eq. 2.35):
\begin{equation}
\ell = \sqrt{2} \frac{\sqrt{\text{TKE}}}{\sqrt{N^2}}
\end{equation}

Limiting ensures physical constraints:
\begin{itemize}
    \item Method 0: $\ell \leq H$ (total water column depth)
    \item Method 1: $\ell \leq \min(z_{\text{surf}}, z_{\text{bot}})$ (distance to nearest boundary)
    \item Method 2: Two-way sweep for smooth vertical variation
\end{itemize}

\subsection{TKE Evolution (Prognostic Step)}

\textbf{Purpose}: Advance turbulent kinetic energy forward in time using an implicit tridiagonal solver. This is the core prognostic equation of GGL90, distinguishing it from diagnostic schemes like KPP.

\textbf{Python Implementation}:
\begin{itemize}
    \item File: \verb|GGL90_ML/GGL90_PY/ggl90_core_driver.py|
    \item Method: \verb|GGL90Driver.step_tke_forward()| (lines 104-228)
    \item Called from: \verb|compute_mixing()| (lines 339-342)
    \item Tridiagonal solver: \verb|main/shared_column_solver.py::solve_tridiagonal()|
    \item System assembly: lines 166-218 (coefficients $a$, $b$, $c$, $\text{rhs}$)
    \item Surface boundary condition: lines 205-210 (Dirichlet: TKE = $m^2 u_*^2$)
    \item Bottom boundary condition: lines 214-218 (Dirichlet or Neumann, controlled by parameter)
\end{itemize}

\textbf{Fortran Source}:
\begin{itemize}
    \item File: \verb|pkg/ggl90/ggl90_calc.F|
    \item Subroutine: \verb|GGL90_CALC|
    \item TKE equation assembly: lines 580-700+ (implicit tridiagonal system)
    \item Dissipation term: line 600+ (\verb|TKEdissipation = ceps * TKE^(3/2) / L|)
    \item Production term: line 607+ (\verb|KappaM * verticalShear|)
    \item Buoyancy term: line 615+ (\verb|-KappaH * Nsquare|)
    \item Tridiagonal solve: lines 750-850+ (Thomas algorithm or equivalent)
    \item Surface BC: lines 630-650+ (Dirichlet condition at surface)
    \item Bottom BC: lines 720-740+ (controlled by \verb|GGL90_dirichlet|)
\end{itemize}

\textbf{Key Equation}:

The TKE prognostic equation:
\begin{equation}
\frac{\partial \text{TKE}}{\partial t} = P + B - \varepsilon + \frac{\partial}{\partial z}\left(\kappa_E \frac{\partial \text{TKE}}{\partial z}\right)
\end{equation}

where:
\begin{itemize}
    \item $P = \kappa_m S^2$ (shear production)
    \item $B = -\kappa_h N^2$ (buoyancy term, positive for unstable stratification)
    \item $\varepsilon = c_\varepsilon \text{TKE}^{3/2} / \ell$ (dissipation, treated implicitly)
    \item $\kappa_E = \alpha \kappa_m$ (TKE diffusivity)
\end{itemize}

\textbf{Implementation Notes}:
\begin{itemize}
    \item Dissipation is split into implicit (\verb|impl_diss_fac|) and explicit (\verb|expl_diss_fac|) parts for numerical stability
    \item Surface TKE boundary condition: TKE$_{\text{surf}} = m^2 u_*^2$ where $m^2 \approx 3.75$ (parameter \verb|m2|)
    \item The tridiagonal system is solved using a shared Thomas algorithm solver (single source of truth)
\end{itemize}

\subsection{Eddy Diffusivity Calculation}

\textbf{Purpose}: Compute eddy viscosity ($\kappa_m$) and eddy diffusivity ($\kappa_h$) from TKE and mixing length. These coefficients drive momentum and tracer mixing.

\textbf{Python Implementation}:
\begin{itemize}
    \item File: \verb|GGL90_ML/GGL90_PY/ggl90_mixing_coefficients.py|
    \item Function: \verb|compute_viscosity_diffusivity()| (lines 17-111)
    \item Called from: \verb|ggl90_core_driver.py::compute_mixing()| (lines 328-331)
    \item Main loop: lines 96-109 (compute coefficients for each vertical level)
    \item Turbulent Prandtl number: lines 82-92 (function of Richardson number)
    \item Background floor: applied at lines 104-109 (matches MITgcm behavior)
\end{itemize}

\textbf{Fortran Source}:
\begin{itemize}
    \item File: \verb|pkg/ggl90/ggl90_calc.F|
    \item Subroutine: \verb|GGL90_CALC|
    \item Viscosity computation: lines 441-461
    \item Key line 448: \verb|KappaM(i,j) = GGL90ck*GGL90mixingLength(i,j,k)*SQRTTKE(i,j,k)|
    \item Prandtl number: lines 560-580 (function of local Richardson number)
    \item Diffusivity from viscosity: \verb|KappaH = KappaM / TKEPrandtlNumber|
    \item Background floor: line 461+ (\verb|MAX(KappaM, viscArNr(k))|)
\end{itemize}

\textbf{Key Computations}:

Eddy viscosity:
\begin{equation}
\kappa_m = \max\left(c_k \ell \sqrt{\text{TKE}}, \nu_{\text{background}}\right)
\end{equation}

Eddy diffusivity:
\begin{equation}
\kappa_h = \max\left(\min\left(\frac{\kappa_m}{\text{Pr}_T}, \kappa_{\text{max}}\right), \kappa_{\text{background}}\right)
\end{equation}

Turbulent Prandtl number (for stable stratification, Ri $\geq$ 0.2):
\begin{equation}
\text{Pr}_T = \min(10, 5 \text{Ri})
\end{equation}

where Richardson number:
\begin{equation}
\text{Ri} = \frac{N^2}{S^2 + \epsilon}
\end{equation}

\textbf{Implementation Notes}:
\begin{itemize}
    \item Background viscosity/diffusivity (MITgcm's \verb|viscArNr|/\verb|diffKrNrS|) are applied as floor values
    \item Maximum caps (\verb|visc_max|, \verb|diff_max|) prevent unrealistic values
    \item Index 0 (surface face) is set to 0 (no surface diffusive flux)
    \item Interior faces k=1..nz-1 carry the mixing coefficients
\end{itemize}

\subsection{Boundary Conditions}

\textbf{Purpose}: Apply physical boundary conditions at the ocean surface and bottom for TKE evolution and mixing coefficients.

\subsubsection{Surface Boundary Conditions}

\textbf{Python Implementation}:
\begin{itemize}
    \item File: \verb|GGL90_ML/GGL90_PY/ggl90_core_driver.py|
    \item Surface TKE: \verb|step_tke_forward()| lines 205-210
    \item Formula: \verb|surf_tke = max(m2 * u_star_sq, tke_surf_min)|
    \item Parameter \verb|m2| $\approx$ 3.75 (default)
    \item Parameter \verb|tke_surf_min| $\approx$ 1e-12 m²/s² (prevents zero TKE)
\end{itemize}

\textbf{Fortran Source}:
\begin{itemize}
    \item File: \verb|pkg/ggl90/ggl90_calc.F|
    \item Surface TKE: lines 630-650+
    \item Uses same formula with \verb|GGL90m2| parameter
    \item Applied as Dirichlet boundary condition in tridiagonal system
\end{itemize}

\subsubsection{Bottom Boundary Conditions}

\textbf{Python Implementation}:
\begin{itemize}
    \item File: \verb|GGL90_ML/GGL90_PY/ggl90_core_driver.py|
    \item Bottom TKE: \verb|step_tke_forward()| lines 214-218
    \item Two options controlled by \verb|use_dirichlet| parameter:
        \begin{itemize}
            \item Dirichlet: TKE$_{\text{bottom}}$ = \verb|tke_bottom| (typically 1e-12 m²/s²)
            \item Neumann: $\partial$TKE/$\partial z$ = 0 (zero flux)
        \end{itemize}
\end{itemize}

\textbf{Fortran Source}:
\begin{itemize}
    \item File: \verb|pkg/ggl90/ggl90_calc.F|
    \item Bottom TKE: lines 720-740+
    \item Controlled by \verb|GGL90_dirichlet| logical flag
    \item Same Dirichlet vs. Neumann choice
\end{itemize}

\textbf{Implementation Notes}:
\begin{itemize}
    \item Surface friction velocity $u_*$ is computed from wind stress: $u_*^2 = \sqrt{\tau_x^2 + \tau_y^2} / \rho_0$
    \item Surface TKE boundary condition represents TKE generation by surface wave breaking and wind stirring
    \item Bottom boundary condition can be Dirichlet (fixed small TKE near bottom) or Neumann (isolating)
    \item Default MITgcm configuration uses Dirichlet bottom BC
\end{itemize}

\subsection{Static Instability Handling}

\textbf{Purpose}: Handle convective instability (N² < 0) through enhanced mixing, representing unresolved convective plumes.

\textbf{Python Implementation}:
\begin{itemize}
    \item File: \verb|main/convective_adjustment.py|
    \item Function: \verb|apply_convective_adjustment()| (lines 1-100+)
    \item Called from: \verb|unified_driver.py| after mixing coefficient computation
    \item Parameter: \verb|ivdc_kappa| controls enhanced diffusivity for unstable regions
    \item When N² < 0, diffusivity is augmented: $\kappa_{\text{total}} = \kappa_{\text{GGL90}} + \kappa_{\text{ivdc}}$
\end{itemize}

\textbf{Fortran Source}:
\begin{itemize}
    \item File: \verb|pkg/ggl90/ggl90_calc.F|
    \item Integrated into main calculation: lines 400-430+ (approximate)
    \item Uses \verb|ivdc_kappa| parameter (typically 0.1 m²/s for convective regions)
    \item Applied when \verb|Nsquare < 0|
    \item Can also use implicit vertical diffusion solver for convective adjustment
\end{itemize}

\textbf{Implementation Notes}:
\begin{itemize}
    \item Static instability occurs when dense water overlies light water (N² < 0)
    \item In reality, this triggers rapid overturning on sub-grid scales
    \item The parameterization represents this with very large vertical diffusivity
    \item Python port uses separate convective adjustment module for clarity
    \item Both implementations add \verb|ivdc_kappa| to the turbulent diffusivity when N² < 0
\end{itemize}

\end{itemize}

\subsection{Grid and Coordinate System}

\textbf{Coordinate Conventions (both implementations)}:
\begin{itemize}
    \item \textbf{z-axis}: Positive upward, z = 0 at surface
    \item \textbf{depth}: Positive downward (depth = $-z$)
    \item \textbf{Vertical index k}: k=0 is shallowest (surface), k=nz-1 is deepest (bottom)
    \item \textbf{Vertical spacing}: \verb|dz[k]| is thickness of cell k
\end{itemize}

\textbf{Staggering Conventions}:
\begin{itemize}
    \item Tracers (T, S) at cell centers
    \item Velocities (u, v) at cell centers (1D column)
    \item TKE at cell interfaces (W-points in MITgcm terminology)
    \item Mixing coefficients ($\kappa_m$, $\kappa_h$) at cell interfaces
    \item N², S² computed at cell interfaces
    \item Mixing length $\ell$ at cell interfaces
\end{itemize}

\textbf{Python vertical arrays}:
\begin{itemize}
    \item \verb|z[k]|: z-coordinate of cell center k [m]
    \item \verb|depth[k]|: depth of cell center k [m], positive
    \item \verb|dz[k]|: thickness of cell k [m]
    \item \verb|tke[k]|: TKE at interface k (between cells k-1 and k) [m²/s²]
    \item \verb|kappa_m[k]|, \verb|kappa_h[k]|: mixing coefficients at interface k [m²/s]
\end{itemize}

\textbf{Fortran vertical arrays}:
\begin{itemize}
    \item \verb|rC(k)|: z-coordinate of cell center k [m]
    \item \verb|rF(k)|: z-coordinate of cell interface k [m]
    \item \verb|drF(k)|: thickness of cell k [m]
    \item \verb|GGL90TKE(i,j,k)|: TKE at interface k [m²/s²]
    \item \verb|GGL90viscAz(i,j,k)|, \verb|GGL90diffKr(i,j,k)|: mixing coefficients at interface k [m²/s]
\end{itemize}

\subsection{Physical Constants}

\textbf{Common constants (both implementations)}:
\begin{itemize}
    \item \verb|gravity| (Python) = \verb|gravity| (Fortran) = 9.81 m/s² (or 9.80665 m/s²)
    \item \verb|rho_const| (Python) = \verb|rhoConst| (Fortran) = 1029.0 kg/m³ (reference density)
    \item \verb|sqrt_two| (Python) = \verb|SQRT2| (Fortran) = $\sqrt{2}$ $\approx$ 1.414
\end{itemize}

\textbf{GGL90-specific constants}:
\begin{itemize}
    \item \verb|ggl90_eps| (Python) = \verb|GGL90eps| (Fortran) = 1e-20 (numerical regularization)
\end{itemize}

\subsection{Boundary Condition Details}

See Section 3.6 for detailed boundary condition implementation. Summary:

\begin{itemize}
    \item \textbf{Surface}: Dirichlet for TKE (TKE = $m^2 u_*^2$), zero flux for mixing coefficients
    \item \textbf{Bottom}: Dirichlet or Neumann for TKE (parameter-controlled), zero flux for mixing coefficients
    \item \textbf{Lateral}: Not applicable in 1D column model
\end{itemize}

\subsection{Unit Conversions}

No unit conversions are needed between the Python and Fortran implementations. Both use SI units consistently:
\begin{itemize}
    \item Length: meters [m]
    \item Time: seconds [s]
    \item Temperature: degrees Celsius [°C]
    \item Salinity: practical salinity units [psu]
    \item Velocity: meters per second [m/s]
    \item TKE: square meters per square second [m²/s²]
    \item Mixing coefficients: square meters per second [m²/s]
\end{itemize}

\subsection{Sign Convention Differences}

\textbf{No sign convention differences} between Python and Fortran implementations. Both use:
\begin{itemize}
    \item z-axis positive upward (z = 0 at surface, z < 0 below surface)
    \item depth positive downward (depth = $-z$)
    \item Vertical gradients computed consistently
    \item Buoyancy term B = $-\kappa_h N^2$ (negative for stable stratification)
\end{itemize}

\textbf{Critical fix (July 2026)}: The Python port initially used in-situ density gradients for N², which introduced spurious compressibility effects. The port was corrected to use potential density gradients (MITgcm's \verb|sigmaR|), matching the Fortran implementation exactly.
